# HOI4 Combat Recorder

Hearts of Iron IVの陸戦で、攻撃判定と命中結果を収集するWindows用ツールです。

## 初回の準備

1. [Python公式サイト](https://www.python.org/downloads/windows/)から **Python 3.12・Windows 64-bit版**をインストールしてください。Python LauncherとTcl/Tkも標準設定のままインストールします。
2. GitHubの「Code → Download ZIP」でダウンロードし、ZIPを展開します。ZIP内から直接起動しないでください。
3. 展開したフォルダーの `setup.cmd` を開きます。初回はインターネット接続が必要です。Pythonの専用環境を作り、`requirements.txt` に記載された依存パッケージを取得します。
4. HOI4を起動し、`起動.cmd` を開いて「収集開始」を押します。

これはソース配布版です。Python不要の実行ファイル版ではありません。別のPCの `.venv` をコピーせず、受け取ったPCでセットアップしてください。

## 陸戦

起動画面の **両陣営に30.00～50.00幅の師団がいる戦闘も別集計** をチェックすると、全戦闘と、幅条件に合う戦闘の統計を分けて表示します。攻撃側・防御側それぞれに該当する交戦中師団が必要です。予備だけでは対象になりません。30.25・49.99などの小数も判定でき、30.00と50.00を含みます。整数への丸めは行いません。

条件付き統計は全体の内数です。結果画面では2列で比較できます。個別記録はチェック時に条件付き戦闘のみ、未チェック時に全戦闘から収集します。個別記録は合計500件（攻撃側250件・防御側250件）に制限し、条件外の処理では枠を消費しません。累積統計は停止まで続きます。条件の途中変更はできません。旧記録を新しい幅条件で再分類することはできません。

幅の取得にゲームの幅計算関数を追加で問い合わせますが、乱数・攻撃・損害処理の追加実行は行いません。地上処理外の別集計は全体側だけに含めます。

防御／突破が適用された判定と、命中／不命中を自動集計します。個別記録を有効にすると、攻撃側250処理・防御側250処理を追加保存します。

「結果を見る」から個別の表と「攻撃先ごとのまとめ」を開けます。まとめには配分・補正後の攻撃合計と、受け手の防御／突破を並べます。同じ番号のa・bは同じ戦闘の応酬ではありません。攻撃先ごとのまとめも記録範囲全体の集計で、複数時間を含みます。

## 保存先と対応環境

- Windows 64-bit。HOI4は別途、正規にインストールしたものが必要です。
- 対応する実行ファイルは `profiles.json` に登録された1.19.2／1.19.3のSHA-256と一致するものです。同じ版名でも未登録の実行ファイルでは接続を中止します。
- 結果は `recordings/` に保存します。結果を公開したい場合以外、これらをGitHubへアップロードする必要はありません。
- ゲームの能力値・乱数・命中結果は変更しません。実行中のプロセスへFridaで接続する方式です。
- 詳細記録は模擬プロセスで検証しています。全環境での動作、追加機能の実ゲームでの実値、マルチプレイでの負荷・同期は未検証です。

ゲーム本体、ゲームから取得した記録、作成者のPython環境はこの配布物に含めません。

## 開発・確認

セットアップ後、陸戦のテストは `.venv\Scripts\python.exe -m unittest test_recorder test_details test_groups -v` で実行できます。ネイティブの計測テストは一時的なPython子プロセスを使い、HOI4には接続しません。

依存ソフトウェアにはそれぞれのライセンスが適用されます。依存関係は同梱せず、セットアップ時に取得します。

### 詳細記録の時間分散

個別の攻撃処理を実時間1秒につき攻撃側25件・防御側25件まで、合計500件まで抽出します。最初の対象処理から1秒経過後の次の対象処理で枠を更新します。余った枠は繰り越しません。ゲーム時間の1秒ではありません。条件に合う処理が少ない場合は収集に長くかかります。全戦闘・幅条件付きの累積統計は抽出で間引かず全件を数えます。これは戦闘単位の均等抽出や無作為抽出ではなく、各時間枠で先に発生した処理を記録する方式です。
